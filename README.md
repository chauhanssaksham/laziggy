# Laziggy

**Instamart, on WhatsApp.**

Tell Laziggy what you need — *"milk, pasta, ingredients for a burger, and something for roaches"* — it curates the cart on Swiggy Instamart. You tap confirm. No app, no list, no scrolling.

---

This repo hosts the landing page (`laziggy.in`). The WhatsApp bot will be added once Swiggy Builders Club access is granted.

## Dev

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Stack

- React Router 7 (Framework mode)
- Tailwind v4
- Deployed on Vercel
- Observability via PostHog + Pino
